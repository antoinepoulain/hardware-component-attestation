Diagrams can be generated by using asciiflow at https://asciiflow.com/#/.  
/!\ diagrams width is limited to 72 characters.

The diagram can then be copied into a .asciio file in the "diagrams" folder.

The diagram is included in the document by using:

```
~~~~ aasvg
{::include diagrams/basic-figure.asciio}
~~~~
{: #basicfigure artwork-align="center" title="Basic Figure for Testing"}
```
